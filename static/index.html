Privacy

      

        Message text is read from the phone on demand and never uploaded. Only
        what is extracted — amounts, merchants, categories, due dates — is
        stored, inside Medha, on this device. The API token is held by the
        Sandeshika server process, never by this browser. No cloud, no account.
      

      
What Sandeshika has learned

      

        Categories you corrected. These override every built-in rule and the
        model, and are applied to past transactions as well as new ones.
      

      


      
Your categories

      

        Add categories that fit how you actually spend. They appear alongside
        the built-in ones everywhere a category can be chosen.
      

      

      
      

      
Export

      

        Your data, in open formats, whenever you want it. Nothing here is
        proprietary and nothing is locked in.
